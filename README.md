# Alpha Cinema

Backend-first project skeleton for a movie application platform built with NestJS, PostgreSQL, Redis, and Docker.

## Tech Stack

- Backend: NestJS
- Database: PostgreSQL
- Cache: Redis
- ORM: Prisma
- Container: Docker / Docker Compose
